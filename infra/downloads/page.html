Up and running in a minute

Install, open, connect to your server.

Android TV

  1. Open the TV address above in a browser or downloader app on the TV, or copy the APK over on a USB drive.
  2. Allow that app to install unknown apps when the TV asks, then install.
  3. Add your server, then choose Link using another signed-in device and approve the code from your phone or computer.

Android

  1. Tap Download for Android, or scan the code from a computer.
  2. Open the downloaded APK. If Android asks, let your browser install unknown apps.
  3. Open Briani Player, add your server and sign in.

Linux desktop

  1. Install GTK 3, libsecret and libmpv from your distribution.
  2. Extract the download:tar -xzf {{linux.file}}
  3. Start it from the new folder:cd briani-player-linux-x64 && ./briani_player
Verify your download

This server keeps a copy of each package only after its SHA-256 matches the digest GitHub publishes for the release. Compare with sha256sum on Linux. The TV and phone downloads are the same APK.
