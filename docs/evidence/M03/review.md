## Contract and verification limits

Idempotent playback replay intentionally returns the existing session with `streamUrl: null`. This is allowed by the nullable schema and keeps ticket persistence hash-only. A client that lost the initial capability must revoke that session and create a fresh one with a fresh key. The server does not reconstruct or persist raw ticket URLs.

This review does not certify ARM64/Pi execution, hardware performance, client playback, signing, or production deployment. Linux containment depends on the supported kernel/Landlock configuration recorded by M02. These remain separate verification gates. The verdict covers ordinary-user API boundaries; the host administrator remains trusted.
