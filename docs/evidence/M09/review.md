## Rollback image boundary follow-up

**P2, corrected in source:** `verify_backup` validates archived lock-file hashes, but restore initially ignored their qBittorrent/Prowlarr references when selecting images. A valid old backup plus changed audited ROOT upstream pins and an accepted historical Briani digest could restore old upstream state; subsequent `up` would use current ROOT Compose images. Reproduction needs only two audited lock sets with differing upstream references; no upstream migration/API incompatibility is assumed. Final `briani.py:399–401` compares archived/current upstream pins and refuses before copying, directing full-stack rollback to the matching audited operations bundle.

## Reviewed protections and limits

Mounted credential absence fails closed: ServiceConnections returns no encrypted secret and RequiredAsync refuses before either integration transport sends a request. Existing files use contained descriptor access, bounded strict UTF-8 reads and group/other permission rejection. API responses expose configured status, not secrets. Administrator groups use live authorization; schema validation rejects unknown/duplicate keys, bad types/controls, excessive arrays and numeric bounds. User preference rows are keyed to the authenticated actor; the migration has a user FK with cascade deletion.

Account changes/revocation retain captured-API identity guards, mounted checks and screen cancellation. Session install combines epoch and cancellation checks through ordered vault writes; no new cross-profile token replay was found. Final ApplicationOperations queue/cache paths have no second inner administrator gate, bounded admission/batches, contained cache-file access and redacted errors. Thumbnail reader acquisition uses the same gate, so pruning cannot race a newly admitted HTTP reader. Snapshot inputs are capped at 1 GiB including WAL; contained directory enumeration caps at 10,001 names. The synchronous SQLite backup has no cancellation overload, so the size cap and successful small-fixture test do not establish a worst-case deadline. No additional concrete defect was found in this final source pass.
