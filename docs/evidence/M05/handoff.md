# M05 handoff

M05 implements the local server-side download lifecycle from source admission through metadata selection, sequential transfer and seeding-safe import. Durable requests and operation journals retain enough information to reconcile after process restarts. The engine adapter is pinned to qBittorrent 5.2.4 / Web API 2.15.1 / libtorrent 2.0.15.0. Metadata is acquired before payload, file layouts account for v1/v2/hybrid torrents, padding and empty files, and selected work starts only after validation and reservations. Imports preserve the qBittorrent payload for seeding; the live proof confirmed equal SHA-256 and same-device inode while qBittorrent remained `stalledUP`.

The key evidence is `docs/evidence/M05/report.md`, the existing independent review at `docs/evidence/M05/review.md`, `/tmp/briani-m05-qbit-engine-final.json`, `/tmp/briani-m05-qbit-local-peer.json`, and `artifacts/dev/20261012T143323.751260Z/`. The API lifecycle proof used the final local image digest `sha256:1b54c4c49cc72738d49e1b74de71276afbb5490eb78019e88b734aa5e148ee66`, restarted the API twice, selected a 15,787,543-byte generated file, imported it, retrieved its JPEG thumbnail and verified that the engine payload remained registered. The trackerless engine harness proved metadata-only v1, v2, hybrid and zero-length mapping without external peers; the hybrid identity changed after metadata and was reconciled by its typed identity.

The focused downloads suite passes 39/39 non-integration tests. Identity (32), media (49), discovery (95), contract generation, unit checks and the final API image build also pass. The corrected `python tools/dev.py test --suite integration` run passed 2 integration tests plus all three real Docker harnesses with exit 0. It records the pinned-engine metadata/control smoke, trackerless v1/v2/hybrid/zero-length metadata mapping, and API admission/selection/restart/import proof under `artifacts/dev/20261012T143323.751260Z/`. The API harness has `--torrent` and `--source`. Fixture and Docker prerequisite failures are explicit nonzero failures. These fixture options changed only the owned M05 prototype harness files; the shared runner and CI wiring remain parent-owned.

The evidence proves local Linux amd64 behavior only.
