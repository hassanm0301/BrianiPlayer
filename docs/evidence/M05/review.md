## Review snapshot

## Independent bounded state-storage experiment

Artifact: `/tmp/briani-m05-state-budget-an7i7_d9/result.json`. A Python sqlite3 3.54.0 experiment inserted generated text with the exact length produced by the existing AES-GCM/Base64 envelope around Base64-encoded 16MiB metainfo, under WAL and FULL synchronous mode. It also wrote a generated 16MiB cache file. Exit 0; the temporary database/cache files were removed after measurement, retaining the JSON evidence only.

Measured encrypted text: 29,826,204 bytes. SQLite main database: 29,859,840 bytes; WAL: 30,043,072 bytes; cache: 16,777,216 bytes. Combined database/WAL/cache: 76,680,128 bytes, excluding 65,536 bytes of shared-memory bookkeeping. The former admission guard accepted 67,108,864 bytes. This demonstrates the separate-state-volume shortage; it is diagnostic SQLite growth evidence, not an EF Core or Pi acceptance test. The corrected six-length-plus-64MiB guard and worker recheck cover this measured case with margin.
