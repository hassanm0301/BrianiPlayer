# Private local candidate

Briani Player now provides folder/photo browsing, Prowlarr Latest/Most seeded/Search, file selection and sequential qBittorrent downloads, verified progressive media delivery, embedded and external playback, administrator/member grants, device-code pairing, preferences, TV D-pad navigation and Docker operations with backup/restore/rollback.

Linux amd64/ARM64 server image archives, an optimized Linux x64 client, an unsigned universal Android APK, an ordinary debug-signed Android local-test APK and an operations bundle are under `dist/`. The manifest, checksums, package SBOM, license notices and source inventories identify the exact private snapshot. Follow the operations guide before creating any deployment; never point an old image at state migrated by a newer version.

Local server/component, generated-media desktop and TV emulator checks pass as recorded in the M11 handoff. The support matrix separates those results from unavailable Windows/macOS hosts and owner-reserved Pi/physical Android testing. Automatic qBittorrent reconnect remains a known reliability limitation; controlled restart recovery preserves bytes and was verified. Optimized playback, critical branch targets, native corresponding-source completeness and release signing remain certification gates. This candidate was not published.
